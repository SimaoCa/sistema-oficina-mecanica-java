# Atividade 21-08 - Tecnicas de Programacao

Este repositorio possui dois projetos independentes do Apache NetBeans.

## Exercicio 1 - Sistema de Oficina Mecanica

Projeto Java desenvolvido no Apache NetBeans para praticar:

- classes e objetos;
- abstracao;
- encapsulamento;
- interface;
- composicao entre `Veiculo` e `Motor`;
- associacao entre `Veiculo` e `Funcionario`;
- menu interativo na classe `Main`.

## Pacotes

- `interfaces`: contrato do sistema da oficina;
- `modelos`: veiculo, motor, funcionario e servico realizado;
- `sistema`: implementacao dos comportamentos da oficina;
- `principal`: classe `Main` com as sete opcoes solicitadas.

O diagrama UML criado para a atividade foi preservado na pasta `diagramas`.

## Exercicio 2 - Sistema de Academia

O segundo projeto esta na pasta `Exercicio2-Academia` e possui:

- cadastro de alunos e instrutores;
- criacao de planos de treino;
- exercicios como parte do plano;
- associacao entre alunos e instrutores;
- interface, encapsulamento e pacotes separados;
- menu interativo com as oito opcoes solicitadas.
